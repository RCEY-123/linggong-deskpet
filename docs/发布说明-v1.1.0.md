### 2) 升级自动补齐新角色

原来的「每个数据目录只补一次」改为**按模板 id 记录已提供过的角色**：老用户覆盖安装后，只补你还没
见过的 8 位；原有角色与设置一个都不动，自己删掉过的角色不会被复活。

### 3) 界面与文案

延续圆润简约风格（圆角控件 / 柔和配色 / 圆点纹理），界面中不再出现具体作品字样，保留

### 4) 文档同步

`使用说明.txt`、`安装说明（先看这个）.txt`、工程说明里的角色清单、语音说明与验收数字全部对齐实测值。

## 安装与升级

- **新装**：双击 `灵工桌宠-安装程序.exe`，选目录 → 完成 → 首次启动自动补齐 13 位角色。
- **覆盖升级**：直接装到同一目录即可，数据目录（`%APPDATA%\AzurLaneDeskPet`）不受影响，新版会补进
  你还没见过的角色。
- **免安装**：直接运行 `app\AzurLaneDeskPet.exe`（与安装负载逐字节一致）。
