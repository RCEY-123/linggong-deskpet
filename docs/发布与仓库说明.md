# 仓库与发布说明（维护者手册）

本文件写给**仓库维护者**：说明这个仓库怎么组织、怎么改、怎么出一版新安装包、怎么发布。

---

## 一、仓库定位

| 项 | 值 |
|---|---|
| 可见性 | **私有（Private）** —— 因为仓库内含第三方游戏角色立绘与语音片段，公开分发存在版权风险 |
| 用途 | 个人使用 + 受邀协作者协作 + 版本归档；安装包随 Release 附件分发 |
| 默认分支 | `main` |
| 许可 | 代码 MIT（见 `LICENSE`）；角色素材不在 MIT 范围内（见 `THIRD-PARTY-NOTICES.md`） |

> 想公开时建议的做法：把 `assets\builtin\characters\**`、`assets\builtin\voices\**`、
> `interface 截图里含立绘的图` 与安装包从公开仓库剔除，只保留 `src\`、`installer\*.cs`、`docs\`
> 与自绘素材；完整版继续留在私有仓库。

## 二、目录职责

```text
src\                    主程序源码（C# 5 / .NET Framework 4.x，UTF-8 无 BOM，csc 编译）
  Program.cs            入口、命令行（--selftest / --selftest-ui / --autostart / --import-builtin / --datadir=）
  Store.cs              路径、日志、配置（含备份/恢复）、角色库、台词解析、语音清单
  Models.cs             数据模型与 AppSettings
  MainForm.cs           主界面与设置外壳
  SettingsForm.cs       六页设置
  CharacterTabs.cs      素材 / 台词 / 语音三页
  PetForm.cs            桌宠分层窗口、气泡、输入条、显示策略应用
  Theme.cs / UiControls.cs   主题与自绘控件（圆角、配色、对勾）
  ImageFx.cs / Audio.cs / DisplayWatch.cs / Llm.cs / SystemWatch.cs / Json.cs / SelfTest.cs
installer\              安装器与卸载器源码 + payload.zip + 构建/验收脚本
  DeskPetSetup.cs       安装器（单文件 exe，payload.zip 作为资源内嵌）
  Uninstaller.cs        卸载器（安全删除、报告、自删除）
  InstallerInfo.cs      产品名 / 版本 / 发布者（**发版时改这里**）
  build-setup.ps1       组装 staging → payload.zip → 编译安装器与卸载器
  test-installer.ps1    安装器 32 项验收
  test-security.ps1     卸载安全 58 项验收（共用目录 / junction / 保护不可绕过）
  final-acceptance.ps1  最终成品 103 项端到端验收（只用安装包）
tools\                  构建与发布工具（不进安装包）
  build.ps1             编译 + 组装 dist\app + 跑核心自检（-RenderUi 出界面截图）
  deliver.ps1           组装交付目录（顶层文档 + 报告 + 截图 + SHA256SUMS + 桌面快捷方式）
  sanitize.ps1          脱敏复检（本机路径 / 用户名 / 仓库名 → 占位符）
  make-icon.ps1         生成 assets\app.ico
assets\builtin\         内置素材（角色 / 台词 / 语音 / UI 贴图 / 音效）
app\                    免安装绿色版（= dist\app 的副本）
docs\                   本仓库文档
测试报告\ / 界面截图\      验收产物（发版时更新）
```

**注意**：所有 `.ps1` 必须是 **UTF-8 with BOM**（中文 Windows 的 PowerShell 5.1 没有 BOM 会按 ANSI 解码
而报语法错）。用编辑器或脚本改完，务必确认 BOM 还在：

```powershell
# 检查（前 3 字节应为 239,187,191）
Get-Content .\installer\final-acceptance.ps1 -Encoding Byte -TotalCount 3
```

`.cs` 文件则相反：**UTF-8 无 BOM**（`csc /codepage:65001`）。

## 三、构建与打包（三步）

```powershell
# 1) 编译主程序 + 组装 dist\app + 核心自检（加 -RenderUi 同时生成 dist\ui-shots 截图）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1 -RenderUi

# 1b) 界面自检（132 项，含菜单/显示策略/关机放行；--render-ui 生成 22 张截图）
.\dist\app\AzurLaneDeskPet.exe --selftest-ui --report=dist\自检报告-界面.txt --render-ui=dist\ui-shots

# 2) 重新打包安装程序（改动主程序或素材后必须重跑，否则安装包里还是旧负载）
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build-setup.ps1

# 3) 验收（三套，全部把数据目录指向 %TEMP% 沙箱）
powershell -NoProfile -ExecutionPolicy Bypass -File installer\test-installer.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File installer\test-security.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File installer\final-acceptance.ps1
```

> 界面自检要用 `Start-Process -Wait` 调用（`&` 调用 WinExe 不会等待、拿不到真实退出码）。

## 四、出一版新版本（改动清单）

按顺序改这些地方，避免出现「文档写 13 位、断言查 5 位」这类不一致：

| 位置 | 改什么 |
|---|---|
| `src\Store.cs` | `ProductName`、`Version` |
| `installer\InstallerInfo.cs` | 版本号、发布者、描述、快捷方式名 |
| `src\SelfTest.cs` | 内置角色 id 列表与条数断言、角色数文案 |
| `installer\final-acceptance.ps1` | `$want` 期望表（id / 中文名 / 台词条数 / 语音条数）、报告标题 |
| `tools\deliver.ps1` | `SHA256SUMS.txt` 标题、快捷方式描述里的版本号 |
| `dist\..\README.md`、`使用说明.txt`、`安装说明（先看这个）.txt` | 角色清单、语音说明、验收数字 |
| `docs\素材清单.md`、`docs\角色内容说明.md` | 新增角色/语音的来源与处理记录 |

## 五、发布流程（GitHub Release）

```powershell
# 1) 组装交付目录（会重写 <交付目录> 全部内容并更新 SHA256SUMS.txt）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\deliver.ps1 -Target 'E:\桌宠\通用版本'

# 2) 脱敏复检（有残留会返回 1）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\sanitize.ps1 -Check

# 3) 同步到仓库工作副本并提交
robocopy 'E:\桌宠\通用版本' . /E
git add -A; git commit -m "release: vX.Y.Z"; git push

# 4) 建 Release 并附安装包
gh release create vX.Y.Z --title "灵工桌宠 vX.Y.Z" --notes-file RELEASE-NOTES.md `
   '灵工桌宠-安装程序.exe' 'SHA256SUMS.txt'
```

Release 说明建议包含：本次改动、验收数字（309 / 132 / 32 / 58 / 103）、安装包 SHA-256、升级注意。

## 六、新增一位内置角色（流程模板）

1. 备好立绘，放到 `assets\builtin\characters\<id>\portrait.png`（透明底 PNG，高 ≤900，体积 ≤1.2MB）。
2. 写 `card.txt`（≥150 中文字符的角色卡）与 `info.json`（id / 中文名 / 附带信息）。
3. 写 `assets\builtin\lines\<id>.txt`：五段台词（问候 ≥5、点击 ≥8、主动 ≥4、待机 ≥3、系统 ≥3），
   必须含「你好 / 你终于回来了 / 你怎么不理我」。
4. 有可公开直链的语音才放 `assets\builtin\voices\<id>\`，并写 `manifest.txt`（音频 ↔ 台词）。
5. 更新 `src\SelfTest.cs` 的角色列表与 `installer\final-acceptance.ps1` 的 `$want` 表。
6. 重跑第三节的构建与三套验收，再看 `docs\素材清单.md` 有没有补记录。

## 七、仓库设置建议

- **About**：描述 + 主题标签建议
  `desktop-pet` `winforms` `csharp` `windows` `dotnet-framework` `llm` `openai-compatible` `vtuber-like`
- **Releases**：发版时附 `灵工桌宠-安装程序.exe` 与 `SHA256SUMS.txt`。
- **Issues**：建议保留开启，作为反馈入口。
- **GitHub Pages**：私有仓库在免费账户下**不提供** Pages；需要网页展示时，把代码与文档拆到公开仓库再开 Pages。
- **协作者**：Settings → Collaborators 邀请，权限给 `Write` 即可。

## 八、维护注意事项

- `installer\payload.zip` 是安装器的负载本体（约 23MB），**每次改素材或主程序都要重跑 `build-setup.ps1`**。
- 仓库内含 22.8MB 安装程序与 23MB 负载包，已在 GitHub 单文件 100MB 限制内；不要往里塞更大的整包。
- 验收脚本会写 `%TEMP%\alp-*` 临时目录并自行清理；跑之前若 %TEMP% 里已有同名残留，安全套件的
  「无残留」断言会失败，手动清一下 `%TEMP%\alp-*` 再跑。
- 改动 `tools\sanitize.ps1` 的替换表时，注意它本身保存着「要抹掉的本机目录名模式表」，
  这就是交付目录里**不含 `tools\`** 的原因（它不会被打进安装包，也不被程序读取）。
