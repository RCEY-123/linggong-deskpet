## 四、人设差异说明（重要）

编写过程中把任务书给定的性格关键词与官方台词表做了逐项比对，结果如下：

### 4.1 初月 —— 关键词与官方人设有冲突，已按官方修正

- 任务书原关键词：「努力家、爱操心、认真、照顾人、偶尔逞强」，偏「老好人」型。
- 官方台词表实际人设：**小恶魔 / 黏人 / 爱撒娇 / 爱捉弄指挥官**。依据包括：
  - 第三人称自称「初月」，口癖「诶嘿嘿」、「♪」；
  - 触摸：「啊，指挥官！没什么啦♪」／「♪～明明没什么事为什么还要跟指挥官搭话？诶嘿嘿~」；
  - 摸头：「这是为了能和指挥官相连，在一开始就被赐予的红线！可以多摸摸哦♪」；
  - 主界面：「初月好像已经离不开指挥官了♪指挥官也是这样的对吧？」；
  - 好感度-失望：「诶，指挥官不理初月了吗……为什么…」；
  - 好感度-陌生：「（初月去了很远的地方。请不要来找我。指挥官，和港区的大家一起多保重——初月）」——赌气出走的反差梗；
  - 2024 情人节礼物：以喂食方式送上巧克力的「啊——」；

- **处理方式**：以官方人设为准重写。主基调为小恶魔／黏人／爱撒娇／爱捉弄，保留一层「认真负责的秘书舰」底色（想把事做好、想帮上指挥官、被摸头会慌、赌气出走的反差），并写入「捉弄要可爱不要刻薄」「赌气可以嘴硬但绝不真的冷淡」的约束。
- 参考图片（初月手持信件与心形巧克力礼盒）与该人设一致，情人节巧克力 / 信件元素已用于台词。

## 五、格式约定（与 `src/Store.cs` 解析器一致）

`src/Store.cs` 的 `ParseText` / `ParseSection` / `ParseLine` 为解析实现，本次内容严格遵守：

- `#` 或 `//` 开头的行是注释，忽略；
- 段落标记 `@问候` / `@点击` / `@主动` / `@待机` / `@系统`（解析器另兼容 `@greet` 等英文与 `@开场` / `@随机` 等别名）；
- 每条台词一行，行首可选 `[权重|字号|配色|加粗]`：权重 1~100、字号 12~24、配色仅用 `gold` / `white` / `rouge` / `indigo` / `candy` / `cyan`，加粗写 `bold`；
- 台词内无换行、无 markdown、无引号包裹、无「（动作）」旁白；
- `@系统` 段使用占位符 `{app}` / `{title}` / `{idle}` / `{time}`（解析器另支持 `{main}`）。
