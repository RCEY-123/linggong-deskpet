### 1.5 `ui\hex-tile.png`

| 项 | 内容 |
|---|---|
| 路径 | `assets\builtin\ui\hex-tile.png` |
| 尺寸 | **256×256** |
| 大小 | 7,189 字节（约 7.0 KB） |
| 透明度 | 不透明（满 alpha） |
| 来源 | **程序化生成**（非取材） |
| 处理 | 逐像素按**环面六边形格子**生成：格点基向量 `<(64,0), (32,64)>`，在 256×256 环面上恰有 16 个格点；对每个像素求最近与次近格点距离 `d1`、`d2`，用 `e = d2-d1` 判定到格边的距离并做抗锯齿描边 |

配色（实测采样）：底色 `#0E1B33`（采样点 (100,100) 实测 `0E1B33`），描边 `#1E3A66`（采样点 (16,32) 实测 `1E3A66`）。格心处有 +3/+4/+6 的极轻微提亮，对比度低、不花哨。

**无缝性**：图案在 256×256 环面上**严格周期**——`x+64` 不一致像素 0 个、`y+128` 不一致像素 0 个；横向接缝差 22、纵向接缝差 1，均小于内部相邻列最大差 41。四边可直接平铺。

> 开发记录：第一版实现把格点循环写成 `i,j ∈ [-2,2]`，导致 (128,0) 与 (-128,0) 这类**同一格点在环面上的重复计数**，使 `d2 == d1`、`e == 0`，生成出一大片假描边。已改为显式枚举环面内 16 个互异格点，并把"次近距离"限制为**不同格点**的距离。
