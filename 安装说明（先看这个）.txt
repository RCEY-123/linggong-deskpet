灵工桌宠  v1.1.0  ·  安装说明（先看这个）
作者：睡不着のHATSUZUKI（灵工巧物 · 天祈智临）
============================================================================

一、怎么装（30 秒）
----------------------------------------------------------------------------
双击本目录最外层那个「灵工桌宠-安装程序.exe」→ 选好安装目录 → 点「安装」。

  · 默认装到  %LOCALAPPDATA%\Programs\AzurLaneDeskPet ，**不需要管理员权限**。
  · 想装到别的盘就点「浏览…」自己选；装进一个已经有别的文件的文件夹也**没关系**：
    安装不会动你原来的文件，卸载也只会删掉本产品自己写进去的那一份。
  · 可选勾选「创建桌面快捷方式」「立即运行桌宠」。
  · 桌面上的「灵工桌宠-安装程序」快捷方式指向的就是这个安装包，双击即可。

二、装完就能用：13 位内置角色
----------------------------------------------------------------------------
安装包里已经内置了 **13 位角色**，**装完立刻可用**，不需要再导入任何素材：

    信浓　初月　欧根亲王　岛风　企业　（这 5 位带语音包 + 语音清单）
    米雪儿　艾卡　佩丽卡　庄方宜　梨诺　叶瞬光　橘福福　蕾米埃尔　（这 8 位带立绘 + 五段台词 + 角色卡）

· 语音：前 5 位每位 16~18 条 mp3，并带 manifest.txt（保证台词和音频一一对上，不会串词）；
  后 8 位**未附语音**，想听声音可以到「角色语音」页自己导入音频、生成清单。
· 台词：每位都有五段（问候 / 点击 / 主动 / 待机 / 系统），并使用该角色自己的语气与称呼。
· 角色卡：人设 + 说话风格 + 开场白 + 输出约束，接大模型时按这张卡演。

第一次打开，左侧「角色列表」里**已经直接有这 13 位**，点一下就能换人（默认选中「信浓」）；
想同时把好几位放到桌面上也可以。如果之前自己删掉过某一位，用「用内置模板新建…」可以一键导回来。
升级安装时，新版会**自动把新增的 8 位补进列表**，原有角色与设置不受影响。

素材版权归各原作权利方所有，仅供本机个人使用、不再分发；逐项来源与处理记录见安装目录里的
`assets\builtin\素材清单.md`。

----------------------------------------------------------------------------
· 深蓝 + 金的设置界面，右上角是宋体写的「灵工巧物 / 天祈智临」。
· 左侧角色列表、中间六个功能页（角色素材 / 角色台词 / 角色语音 / 角色卡 / 互动设置 /

  版本与作者）。
· 右下角「开启桌宠」——点下去界面收起，桌面上就出现你设置好的角色。
· 嫌桌宠一直压在最上面挡事？齿轮 →「桌宠显示」里可以选：始终保持在最上层 /
  其他应用获得焦点时冻结（沉到窗口最底层 + 停动画，回到桌面自动恢复）/
  其他应用全屏时隐藏（全屏游戏 / 视频时进后台，退出全屏再显示）；
  桌宠上右键 →「桌宠显示」也能随手切。默认已经打开「其他程序全屏时自动隐藏桌宠」。
· 点角色会 Q 弹一下并冒出气泡说话（固定台词模式）；切到「大模型对话模式」后，
  除了气泡还会出现一个输入条，可以直接跟她聊天。

四、安全与隐私（这次发布的重点）
----------------------------------------------------------------------------
1) **不会误删你的文件。** 安装时会把写进去的每个文件 / 目录记进安装清单（files.json）；
   卸载时只删清单里的东西，清单外的一律保留并在报告里列出来。目录只在**已经空了**
   的情况下才会被删；不跟随目录联接 / 符号链接（junction / symlink），不会顺着链接
   删到外部素材库；数据目录必须带本产品写的标记才允许清理。
2) **安全检查拒绝后不会"绕过"。** 如果卸载程序判定某个目录不该删（系统目录、盘符根
   目录、用户主目录、重解析点…），它会直接放弃，**不会**再安排任何延迟删除脚本去
   偷偷删掉；即使是删被占用的文件，也只逐条删清单里的具体文件，绝不整目录递归删除。
3) **大模型 API Key 不是明文。** Key 保存在数据目录的 config.json 里，写盘前用
   Windows 自带的 DPAPI 按「当前用户」加密，文件里只能看到 dpapi:v1: 开头的一串密文；
   拷到别的电脑或别的用户下都解不开。界面上照常显示/复制明文，功能没有任何变化。
4) **系统事件监听默认关闭**，开启必须显式授权；只读前台程序名 / 窗口标题 / 键鼠空闲，
   只在内存里保留 30 分钟，不写盘、不外传；拒绝授权不影响其它任何功能。
5) **不出网、不联网校验。** 除了你自己配的大模型接口，程序不向任何服务器发数据。
6) 安装程序 **没有**要求管理员权限，也不会改系统目录、服务、驱动或防火墙。

五、卸载
----------------------------------------------------------------------------
开始菜单 →「灵工桌宠」→ 卸载，或者直接运行安装目录里的「卸载-灵工桌宠.exe」。
卸载会在确认后删除：安装目录里本产品的文件、用户数据目录（角色 / 立绘 / 台词 / 语音 /
日志 / 配置）、快捷方式、卸载注册表项，并在最后报告「共删除 N 个文件 / M 个目录」以及
「已保留」「安全校验拒绝」的条目清单。

静默卸载（脚本用）：
    卸载-灵工桌宠.exe /S --purge-data --report=<报告文件>

八、如果你以前装过旧版本
----------------------------------------------------------------------------
  · 直接双击新安装包、装到同一个目录就行：程序文件会被替换，%APPDATA%\AzurLaneDeskPet
    里的角色素材 / 台词 / 设置**全部保留**。
  · 新版安装时会读上一版的安装清单（files.json），把「上一版写过、这一版已经不要了」的
    文件顺手清掉（例如早期内置的武藏 / 新泽西），并且**只删清单里列出的、不在本次负载里的**
    文件；清单外的文件一律不动。
  · 万一你的安装目录里还留着**更早版本**（v1.0.3 及以前）写下的文件——那些版本的清单早被
    覆盖掉了，安装器出于「不误删无关文件」的原则会把它们保留下来，症状是「用内置模板新建」
    里多出早已移除的角色。这时可以用工程目录里的清理工具（默认只列清单、不删；该脚本随 tools\ 一起不放进交付副本）：
         powershell -NoProfile -ExecutionPolicy Bypass -File tools\clean-legacy-install.ps1 -InstallDir "<安装目录>"
         powershell -NoProfile -ExecutionPolicy Bypass -File tools\clean-legacy-install.ps1 -InstallDir "<安装目录>" -Apply
  · 最省事的做法：装到一个**全新的空目录**（点「浏览…」自己选一个），一次到位、没有任何历史包袱。

九、关于「脱敏」的说明（哪里干净、哪里是工具自身的匹配表）
----------------------------------------------------------------------------
  · **安装包本体与装完之后的每一个文件都是干净的**：主程序 exe、卸载器 exe、安装程序 exe
    做过 UTF-16（偶/奇两种对齐）+ UTF-8 三路字符串提取，本机盘符路径、用户名、素材参考目录名、
    来源仓库名**全部 0 命中**；同时断言创作者标识「睡不着のHATSUZUKI / 灵工巧物 / 天祈智临」在位。
    打包进安装包的文档（使用说明.txt、素材清单.md、角色内容说明.md）已把本机路径替换成
    `<工程根>` / `<素材库>` / `<用户参考图>` 之类的中性占位，残留 0 处。
  · 交付目录里的**测试报告**也做过一次脱敏：真实用户名 → `<用户>`，`%TEMP%` 绝对路径 → `%TEMP%`，
    工程根路径 → `<工程根>`，交付路径 → `<交付目录>`。
  · 交付副本里**没有** `tools\` 目录：`sanitize.ps1` / `deliver.ps1` 为了做脱敏，本身必须保存
    一份「要抹掉的本机目录名模式表」，而那正是本次要求抹掉的本机环境信息；它们是构建工具，
    不会被打进安装包、也不会被程序读取（需要重新构建时用工程目录里的 tools\ 即可）。
