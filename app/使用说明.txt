灵工桌宠  v1.1.0        作者：睡不着のHATSUZUKI（灵工巧物 · 天祈智临）
============================================================================
一个把桌宠放到桌面上的桌面宠物软件。可以自己导入立绘、台词、语音
和音效，也可以接大模型让她跟你聊天。全部设置都在界面里点，不用改配置文件。


一、安装
----------------------------------------------------------------------------
1. 双击「灵工桌宠-安装程序.exe」。
2. 安装界面里可以自定义安装目录（默认装在当前用户目录下，**不需要管理员权限**）：
      %LOCALAPPDATA%\Programs\AzurLaneDeskPet
   想装到别的盘就点「浏览…」自己选。
   · 如果选的目录里已经有别人的文件，安装程序会提示你：**安装不会动那些文件，
     卸载时也只会删掉本产品自己的文件**（详见第九节）。
3. 可选：勾选「创建桌面快捷方式」「立即运行桌宠」。
4. 卸载：开始菜单 → 灵工桌宠 → 卸载，或者在「设置 → 应用」里卸载
   「灵工桌宠」。


二、第一次打开
----------------------------------------------------------------------------
第一次启动会弹出桌宠设置界面（深蓝+金，右上角是宋体的「灵工巧物 / 天祈智临」）。
安装包内置了 **13 位角色**，装完就能直接用：

    信浓 / 初月 / 欧根亲王 / 岛风 / 企业 / 米雪儿 / 艾卡 / 佩丽卡 / 庄方宜 / 梨诺 / 叶瞬光 / 橘福福 / 蕾米埃尔

前 5 位带完整语音包与语音清单（各 16~18 条）；后 8 位都是立绘 + 五段台词 + 角色卡，其中米雪儿 /
艾卡 各带 2 条、佩丽卡 / 庄方宜 各带 1 条公开试听语音（附清单，可自行补齐），梨诺 / 叶瞬光 /
橘福福 / 蕾米埃尔 未附语音——想听声音可以到「角色语音」页自己导入音频并生成清单，
软件会自动把语音和台词对上。

界面分三块：
  · 左侧「角色列表」——显示你创建的所有角色，可以新建、用内置模板新建、复制、删除。
    不同角色的立绘、台词、语音、角色卡、音效完全独立，互不影响。
  · 中间六个功能页——角色素材 / 角色台词 / 角色语音 / 角色卡 / 互动设置 / 互动音效。
  · 右上角齿轮——声音、大模型 API、保存路径、日志、常规、桌宠显示、版本与作者。
    右下角「开启桌宠」——点下去界面收起，桌面上就出现你设置好的角色。

窗口可以自由拉伸、也可以最大化：各区域会跟着一起铺满，不会只剩左上角一小块。

第一次启动后，左侧「角色列表」里**已经直接有这 13 位**，点一下列表里的人物就能换人，
想同时把好几个放到桌面上也可以。默认选中「信浓」。
（升级安装的话，新版会**自动把新加的 8 位补进你的角色列表**，原有角色与设置一个都不动；
自己删掉过的角色不会被自动补回来。）

素材版权归各原作权利方所有，仅供本机个人使用、不再分发；逐项来源与处理记录见
数据目录里的 `assets\builtin\素材清单.md`（随安装包一起提供）。


三、六个功能页怎么用
----------------------------------------------------------------------------
① 角色素材
   · 「导入图片…」支持 PNG / JPG / BMP / GIF（取首帧），可多选。
   · PNG 带透明通道的立绘会直接变成「站在桌面上」的桌宠；
     如果图片是不透明的照片/壁纸，软件会把它按圆角金边卡片样式显示。
   · 想要透明效果：选中图片 → 「一键抠图」，程序会从四边取背景色做抠图，
     原图自动备份到 images\_originals\，结果另存为同名 .png。
   · 「设为当前立绘」决定桌面上用哪张。

② 角色台词
   · 五类台词分开管：「问候」（打开桌宠时）、「点击互动」、「主动对话」、
     「待机」（长时间没互动，例如「你怎么不理我…」）、「系统事件」。
   · 每条台词可以设权重（抽中概率）、字号、配色、加粗，也可以绑定某个音频文件。
   · 「导入台词文件…」支持 .txt / .json（含旧版插件的台词包格式）；
     「导出台词到文件…」导出的文件可以直接再导入，也可以编辑后再导入。

③ 角色语音
   · 「导入音频…」把 mp3 / wav / ogg / m4a 放进角色的 voices 目录。
   · **重要**：台词音频应当有一份「清单」，否则会出现说这句、放那句的串词问题。
     点「生成/更新清单模板」会生成 manifest.txt，每行是：
          台词文本|音频文件名
     例如：  妾身…困了…|v01.mp3
     核对保存后点「重新载入清单并校验」，界面会告诉你匹配上了多少条台词。
     也支持「音频文件名|台词文本」反过来写、CSV（逗号分隔）和 manifest.json。
     没有清单时，程序会用「音频文件名当台词文本」来兜底匹配。

④ 角色卡（仅在接入大模型时可用）
   · 这里写的就是给大模型的提示词：角色设定、说话风格、开场白、补充要求、玩家称呼。
   · 「测试当前角色卡」可以直接让模型说一句，看看像不像。
   · 也可以从 txt / json 导入角色卡（支持【角色设定】【说话风格】这种小标题分段），
     或者用「生成模板」起个头。

⑤ 互动设置
   · 对话模式：固定台词模式（点一下随机说一句）/ 大模型对话模式（点一下按角色卡回一句）。
     当前生效的那个按钮会带**金色对勾**，下面还有一行「当前：…」的说明；另一个按钮是普通样子，
     鼠标悬停只会有一圈浅蓝高光，不会和「已选中」混淆。点了就会立刻生效并保存。
   · 主动对话：勾上后按你设的间隔（30 秒 ~ 几小时，也可直接点「2 分钟」等预设）
     让桌宠自己开口，台词从「主动对话」池里随机抽。
   · 系统事件搭话：勾上后会问你授权（见第六节）。
   · 气泡停留秒数（0 = 不自动关闭）、立绘大小、点击 Q 弹动画与时长、是否显示输入框。

⑥ 互动音效
   · 内置两套预设：音效1（按压/松开）、小黄鸭，可直接试听；也可以导入自己的音效，
     分别指定「按压」「松开」「气泡出现」三个槽位。
   · 音效音量在「齿轮 → 声音」里统一调。


四、桌面上的桌宠
----------------------------------------------------------------------------
· 拖动：按住左键拖到任意位置，松手后位置会被记住（右键菜单可「重置位置」）。
· 点击：会先微微压缩再弹起（Q 弹），同时播放按压/松开音效；
     · 固定台词模式 → 弹出气泡随机说一句，如果这句有对应语音就一起播；
       **这句语音没播完之前，再点只会继续 Q 弹，不会换下一句台词**（避免被说半句就打断）。
     · 大模型对话模式 → 按角色卡回一句，并在桌宠下方出现输入框，打字回车即可继续聊。
       回答只出现在头顶气泡里，不会跑到对话框里。
· 气泡永远贴在角色头顶上方（不遮住角色）；输入框落在角色正下方，下方放不下时自动挪到角色左侧。
· 右键菜单：互动一下 / 打开设置界面 / **关闭桌宠并打开设置界面** / 切换或添加角色 /
  **桌宠显示** / 重置位置 / 隐藏这个角色 / 退出程序（桌宠一起关掉）。
  · 「关闭桌宠并打开设置界面」= 只把桌面上的桌宠收起来并回到设置界面（想改完再开一次时用）；
  · 「退出程序」= 连程序一起关掉，托盘图标也会消失。
  · 「切换或添加角色」里可以**同时把多个角色放到桌面上**，每个角色各自独立。
  · 「桌宠显示」= 随时切换下面 4.1 里的三种显示方式，还能一键开关「全屏时自动隐藏」。
· 托盘图标：双击打开设置界面；右键可以看到显示/隐藏桌宠、数据目录、日志与退出。


4.1 桌宠显示方式（不想让它一直压在最上面时用）
----------------------------------------------------------------------------
打开桌宠时它默认「始终保持在最上层」。如果嫌它挡住别的软件，改这里：

  齿轮 →「桌宠显示」，或者直接在桌宠上**右键 →「桌宠显示」**，三选一：

  ① 始终保持在最上层（默认）
     桌宠永远浮在所有窗口上面，和以前一样。

  ② 其他应用获得焦点时冻结
     你一切到别的软件，桌宠就自动**沉到窗口最底层并冻结**：
       · 不再播放 Q 弹动画、不再主动说话，也不会挡住你正在用的程序；
       · 头顶的气泡和输入框会一起收起来（可在同一页里关掉这个行为）；
       · 一回到桌面、或者点一下桌宠，马上恢复。
     适合：工作时不想被桌宠挡住，但闲下来还想看看她。

  ③ 其他应用全屏时隐藏
     平时仍然浮在最上面；一旦有别的程序**全屏**（全屏游戏 / 视频 / 演示 / 投屏），
     桌宠就进入**后台运行**：窗口隐藏、动画与搭话暂停（几乎不占资源），
     退出全屏回到桌面后自动重新显示。
     适合：既想看到桌宠，又不想在全屏游戏里被它压住。

另外还有一个**任何模式下都生效**的开关：

  「其他程序全屏时自动隐藏桌宠」——默认**开启**。哪怕是「始终最上层」模式，
  有程序全屏时也会把桌宠收进后台，回到桌面再显示（开关就在同一页，右键菜单里也能切）。

它是怎么判断的（不用担心中毒或偷窥）：
  · 只用 Windows 自带的窗口接口判断「当前前台窗口是否盖满屏幕」，**不截屏、不读窗口标题**；
  · 桌面本身、任务栏、开始菜单、以及桌宠自己的窗口都不算「别的程序」，不会误触发；
  · 只有在需要时才每 0.3 秒检测一次；选「始终最上层」并且关掉全屏自动隐藏时**完全不检测**
    （静置 CPU 依然是 0）；
  · 多显示器时按屏幕分别判断：另一块屏上的全屏程序不会把这块屏上的桌宠收走。


五、接入大模型（兼容本地与云端）
----------------------------------------------------------------------------
齿轮 →「大模型 API」：
· 预设下拉里有 8 个选项，选完自动填好地址和模型名：
    云端：DeepSeek 云端 / OpenAI 云端 / 云端·OpenAI 兼容中转
    本地：Ollama（11434）/ LM Studio（1234）/ OneAPI-NewAPI（3000）/ llama.cpp（8080）
    也可以选「自定义」自己填。
· 需要 Key 的只有云端；本地服务一般留空。
· 填完点「测试连接」，会立刻返回结果（鉴权失败、地址不对、连不上都会给出具体原因和建议）。
· 角色是否用大模型，在「互动设置 → 对话模式」里按角色单独切换。
· 隐私：只有你自己填的这个接口会收到对话内容；密钥保存在本机 config.json 里，
  不会上传到任何第三方服务器。


六、系统事件监听与主动搭话（需要授权）
----------------------------------------------------------------------------
开启「互动设置 → 根据系统事件/当前操作主动搭话」时，会弹出授权说明：
· 只读取三项：当前前台窗口的程序名、窗口标题、键鼠空闲时间（用于判断你是不是在打游戏）。
· 只在内存里保留最近 30 分钟，不写磁盘、不外传；关掉开关就停止采集。
· 授权后，桌宠能说出「汝刚刚是在玩 {app} 么…？」这类台词；
  接了大模型时，模型会拿到一句人话上下文，自己组织怎么开口。
· **拒绝授权不会影响其它功能**，只是这项不可用；之后想用再勾选一次即可重新授权。


七、出错了怎么办
----------------------------------------------------------------------------
程序遇到错误会弹窗，里面写着「错误日志已生成」并给出日志完整路径，按钮可以
「复制日志路径 / 打开日志文件夹 / 打开日志文件」。

如果要求助，请把那个日志文件**直接上传给 AI 或相关技术人员**，不要只截弹窗的图——
日志里有完整的错误原因和调用位置，比截图有用得多。

日志位置：数据目录\logs\pet-年月日.log
（数据目录默认 C:\Users\<你>\AppData\Roaming\AzurLaneDeskPet，可在「齿轮 → 保存路径」里改，
  并支持一键迁移已有角色素材。）


八、文件都放在哪
----------------------------------------------------------------------------
· 程序目录：安装目录，含 AzurLaneDeskPet.exe、assets\builtin\（13 位内置角色的立绘/台词/
  角色卡/语音）、卸载-灵工桌宠.exe、install.json 与 files.json（安装清单）。
· 你的数据（角色 / 立绘 / 台词 / 语音 / 音效 / 日志 / config.json）：
  默认 %APPDATA%\AzurLaneDeskPet，可在「齿轮 → 保存路径」里改到别的盘，换电脑直接整目录拷走。
· 每个角色的目录结构：
      characters\<角色id>\
          profile.json      角色设置
          images\           立绘（_originals\ 是抠图前的备份）
          lines\            导入过的台词文件
          voices\           音频 + manifest.txt 语音清单
          sfx\              自定义音效
          card 内容保存在 profile.json 里


九、卸载时不会动别人的文件（v1.0.5 起，v1.0.6 复核）
----------------------------------------------------------------------------
卸载程序只删除「安装时自己写下的东西」，并做了多重保护：
· 安装时会把写入的每个文件/目录记进 `files.json`（安装清单）；卸载时**只删清单里的文件**，
  清单外的文件一律保留，并在报告里列出「已保留（非本产品文件）」。
· 目录只在**已经空了**的情况下才删除；安装目录里只要还有别人的文件，目录就会留着。
· 不跟随**目录联接 / 符号链接**（junction / symlink）：遇到重解析点会跳过并记录，
  不会顺着链接删到外部素材库。
· 数据目录必须带有本产品写的标记文件（`.azurlandeskpet-data`）或含本产品的 config.json，
  否则卸载程序拒绝删除它，只提示路径让你自行确认。
· 如果安全检查判定某个目录不该删（例如系统目录、盘符根目录、用户主目录），
  卸载程序会**直接放弃**，不会安排任何"延迟删除"去绕过它。
· 万一有文件被占用删不掉，只对**清单里的具体文件**做延迟删除，绝不做整目录递归删除。

十一、常见问题
----------------------------------------------------------------------------
Q：桌宠挡住别的东西了？
A：两种办法：
   ① 急着用电脑：桌宠上右键 →「桌宠显示」→「其他应用获得焦点时冻结」——以后你切到别的
      软件它就会自动让位；或者选「其他应用全屏时隐藏」，全屏游戏/看视频时它会自己躲起来。
   ② 临时挪开：直接拖走；或者右键「隐藏这个角色」，托盘图标双击可以叫回设置界面。
   （齿轮 →「桌宠显示」里也有同样的设置和详细说明。）

Q：点了桌宠没反应？
A：立绘的透明区域不会接收点击（这样才不挡桌面）。点在人物身上，或者换一张
   不透明的立绘（会被显示成卡片，整张都可点）。

Q：说话很大声/没声音？
A：「齿轮 → 声音」里有总音量、互动音效开关、角色语音开关；单个角色还能在
   「互动音效」页里单独关掉。

Q：大模型模式点了没回？
A：多半是接口没接通——「齿轮 → 大模型 API → 测试连接」会直接告诉你原因。
   没有配置接口时，大模型模式会自动退回固定台词，不会哑掉。

Q：怎么换成内置的其它角色？
A：装好后这 13 位**已经都在左侧「角色列表」里**了，直接点一下就换人；如果之前自己删掉过
   某一位，用「用内置模板新建…」把它导回来即可（信浓是默认那位）。

Q：会占用很多资源吗？
A：空闲时桌宠不重绘，只在点击动画、说话和主动对话时才动；大立绘只解码一份并复用
   双缓冲画布，不缓存多份缩放帧。
   「桌宠显示」的检测也极轻：默认设置下实测**空闲 20 秒只多花 31 毫秒 CPU**
   （约 0.15% 单核，前台窗口没变时几乎不做事）；把「其他程序全屏时自动隐藏桌宠」关掉
   之后**完全不做检测**（0 毫秒）。

Q：切到别的软件，桌宠怎么突然不见了 / 不动了？
A：这是「桌宠显示」里的正常行为，不是崩溃：
   · 选「其他应用获得焦点时冻结」→ 它沉到窗口最底层，被别的窗口盖住了（还在桌面上）；
   · 有其他程序全屏（含「始终最上层」模式下的默认开关）→ 它进后台隐藏了。
   回到桌面、退出全屏，或者点一下桌宠（右键菜单「互动一下」也行），马上就会回来。
   想让它一直浮在最上面：齿轮 →「桌宠显示」→「始终保持在最上层」，并关掉
   「其他程序全屏时自动隐藏桌宠」。

Q：怎么彻底删干净？
A：运行「卸载-灵工桌宠.exe」；它会删除安装目录里本产品的文件、数据目录
   （含角色素材）、快捷方式与注册表项。若你在「保存路径」里改过目录，卸载时会
   连带清理（前提是那个目录带着本产品的标记文件）。

Q：升级到新版本，要先卸载旧版吗？
A：**不用，也建议不要。** 直接运行新版安装程序覆盖安装即可，角色、台词、语音、
   设置都会原样保留（安装器只覆盖本产品的文件）。
   如果你先卸载：卸载界面里那个「同时删除 %APPDATA%\\AzurLaneDeskPet（素材/台词/
   图片/设置）」默认是**勾上**的 —— 一旦执行，你的角色与设置就一起没了。
   所以升级请直接覆盖安装。

Q：我的设置到底存在哪？会不会丢？
A：全部存在数据目录（默认 %APPDATA%\\AzurLaneDeskPet）：
   · config.json —— 音量、大模型 API、显示方式、当前角色等全局设置；
   · characters\\ —— 每个角色的立绘 / 台词 / 语音 / 角色卡 / 互动设置。
   程序每次保存都会另外留一份 config.json.bak；万一 config.json 损坏，下次启动会
   自动从备份恢复（连备份都读不出来时会先把坏文件改名成 config.json.bad-* 留档，
   绝不会直接覆盖掉你的配置）。

Q：API Key 存在哪里？会不会被别人偷走？
A：Key 保存在数据目录的 config.json 里，**不是明文**。程序写入时用 Windows 自带的
   DPAPI（数据保护接口）按「当前用户」加密，文件里只能看到 `dpapi:v1:` 开头的一串
   密文：
       "apiKey": "dpapi:v1:AQAAANCMnd8BFdERjHoAwE/Cl+sBAAAA...=="
   这样即使 config.json 被拷到别的电脑、或者被别的机器上的程序读到，也解不出你的
   Key（密钥由 Windows 用你的登录凭据派生，只在本机本用户可解）。界面上依旧照常
   显示/复制明文，功能没有任何变化。
   提示：本机同一用户下的其它程序仍可调用 DPAPI 解回来，所以请照常保护好自己的
   电脑账户；装完不想留 Key，在设置里把 Key 清空并保存即可。
